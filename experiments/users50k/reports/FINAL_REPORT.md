# Итоговый эксперимент GPT-2 + RL на KION

Обучение: 50 000 пользователей. Train до 2021-07-01, validation — июль, test — август. Validation/test фиксированы относительно эксперимента 10k. История содержит только предыдущие дни; порядок внутри прошедшего дня задан по ID и является приближением.

Основной RL-вариант выбран **до test**: `raw_kl001`. Правило: максимальный validation reward@10 при снижении validation NDCG@10 не более 5%. Остальные варианты — заранее обученные абляции; по test модели не перенастраиваются.

## Генерация пяти объектов

Для всех моделей использованы одинаковые реальные стартовые контексты, по одному на пользователя. Показаны greedy и sampling из полного распределения при temperature=1. Маски повторов отсутствуют. Каждый сгенерированный объект добавляется в контекст независимо от неизвестного отклика.

| baseline / sample | 0.5679 → 0.5864 | 2.34% | 4.96 |

| raw_kl01 / sample | 0.5967 → 0.6165 | 1.95% | 4.95 |

Изменение reward по шагам смешивает изменение выбранных объектов и истории. Поле `reward_frozen_history` в JSON оценивает те же объекты на неизменной исходной истории и помогает отделить чувствительность reward model к синтетическому контексту. Отклик на цепочки не наблюдается: это диагностика сдвига распределения, а не оценка реального суммарного потребления.

## Долгосрочная цель

Рассмотрен возврат в течение семи дней после наблюдаемого дня активности. В расчёт включены только полные окна внутри соответствующего временного split.

| Split | Дней с полным окном | Доля наблюдаемого возврата |
|---|---:|---:|
| train | 228460 | 0.5302 |
| validation | 41342 | 0.4860 |
| test | 19929 | 0.4771 |

Это описательная proxy-статистика выбранных пользователей. В KION сохранены агрегированные user–item события с последней датой просмотра, поэтому полная траектория ежедневных посещений не восстановлена. Для обучения return reward нужны только признаки, доступные до решения; будущий возврат служит меткой с полным окном наблюдения. Для причинного эффекта на удержание нужен онлайн-эксперимент или подходящие логи показов для обоснованной off-policy оценки.

## Выводы и ограничения

На validation увеличение train с 10k до 50k улучшило NDCG и качество reward model, но снизило Recall. RL увеличил предсказанный reward; слабая KL-регуляризация вызвала больший сдвиг policy. Эти выводы относятся к предсказанному proxy, а не к фактическому досмотру или удовлетворённости.

Оценка ограничена активными warm-пользователями и train-каталогом. Reward model обучена только на наблюдавшихся взаимодействиях и имеет ограниченную точность и оптимистичное смещение. Один seed, короткий RL-запуск, неполные истории, суточная точность дат и отсутствие истинной длительности объектов ограничивают интерпретацию. Штраф повторов относится только к последним 64 объектам контекста. Эффект предпочтения короткого контента по этим данным не проверен.

## Результат основного варианта на test

Для `raw_kl001` разность NDCG@10 относительно baseline: -0.00027 (-0.51% относительно baseline); разность предсказанного reward@10: +0.04910. Интервалы неопределённости приведены выше. Порог 5% применялся при выборе на validation; соблюдение этого ограничения на test не предполагается заранее.
